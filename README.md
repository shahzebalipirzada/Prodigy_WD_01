# Tandoori Tadka Restaurant UI

A clean, single-page restaurant landing page built with vanilla HTML, CSS, and JavaScript.

## What it includes

- A calm hero section with a focused call to action
- A compact menu section with food imagery, prices, and short descriptions
- A balanced gallery section using the existing image set
- A simple about section
- A clear contact section with business details
- Responsive layout for mobile and desktop

## Asset structure

All images are organized under `Prodigy_WD_01/assets/images/`:

- `hero/` for the main hero image
- `menu/` for featured menu item images
- `gallery/` for the remaining food photography
- `misc/` for existing artwork files kept outside the UI

## Files

- `Prodigy_WD_01/index.html`
- `Prodigy_WD_01/style.css`
